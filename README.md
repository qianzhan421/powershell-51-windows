# powershell-51-windows

A Claude Code skill: a practical cheat sheet for working with **Windows 11 / PowerShell 5.1**
from the command line — syntax differences from bash, alias traps, encoding pitfalls,
execution policy, and cmd/batch interop.

## Install

Copy `SKILL.md` into your skills directory:

    ~/.claude/skills/powershell-51-windows/SKILL.md

Claude Code picks it up automatically on the next session.

## Contents

1. Which shell am I actually in
2. Terminal panel constraints
3. PowerShell 7 syntax that 5.1 rejects
4. Alias traps (curl, sc, ls...)
5. Paths and quoting
6. Encoding (the most common 5.1 footgun)
7. Execution policy and exit codes
8. Common command equivalents
9. cmd / batch interop
